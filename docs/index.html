Token Buddy

A pixel desk robot for the ESP32 CYD 2.8" and 2.4" that shows your Claude Code usage limits, reacts while Claude works and while you type.

1Install on the CYD

Plug the CYD into this computer with a USB cable, then click the button for your model. Works in Chrome or Edge on a computer.

CYD 2.8"ESP32-2432S028R Open this page in Chrome or Edge on a computer. This page must be opened over https.
CYD 2.4"ESP32-2432S024R Open this page in Chrome or Edge on a computer. This page must be opened over https.

Not sure which one? Measure the screen diagonal. If you pick the wrong one the screen stays black: just install the other.
If no device shows up, install the USB driver for the CH340 chip and try again.

2Connect it to WiFi

  1. After the install the CYD creates a WiFi network called TokenBuddy-Setup.
  2. Join it with your phone, pick your home WiFi and type its password.
  3. The CYD restarts and connects. Done.

3Install the bridge on your PC

The bridge reads your Claude Code usage and tells the CYD. Windows only for now; you need Claude Code logged in and Python 3.

Download Token Buddy

  1. Unzip it, open the bridge folder and double-click install_windows.bat.
  2. If Windows asks about the firewall, allow access on private networks.
  3. The CYD finds the bridge by itself within a few seconds.

4Make it yours

  • Open http://tokenbuddy.local to pick a color theme or make your own.
  • Hold the screen for a second to switch theme; tap it to peek at your limits.
  • Print the pixel robot case: get it on MakerWorld, or take the files from the case folder.
